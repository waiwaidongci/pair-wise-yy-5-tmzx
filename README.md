# 手工织锦上机配伍台

直接打开 `index.html` 使用（纯前端单文件，数据存于浏览器 localStorage）。

在原"纹样排版台"基础上扩成上机配伍台，解决两组色线来自不同染缸、换线色差的问题。四个页签：

- **排版台**：经纬网格绘制、色位（含"空·不织"）、单点/十字/小菱形基础块、撤销重做、用色统计与断线风险。
- **上机配伍复核**：纹样每次保存即留版，并按实际色位生成"待复核用色清单"，逐项登记染缸号、染纱批次、复测 ΔE 与样卡比对结果。
- **机台·染缸·交接**：查看机台占用、待上机队列、染缸晾干状态；办理上机/下机、晾干放行，全程交接记录（时间、事件、交接人）。
- **历史版本**：每次保存留不可变版本与复核单，可查看或恢复到排版台。

配伍判定规则：

1. 染缸、批次必须登记，批次色距必须复测（ΔE ≤ 1.5）且与样卡相符，否则退回配色；
2. 同一染缸上一份未登记晾干，不能接下一份；同一复核单内也不允许两色位重复占同一缸；
3. 图案行列、色位或基础块戳印一改动（画布指纹变化），现有复核单即时失效并要求重排，保存后作废旧单、另出新复核单；已通过的旧单留档不抹除；
4. 复核通过即锁定相关染缸，办理上机后占机，下机后释放。

数据三类分别承载（localStorage 分键）：画布与版本 `zfl31Canvas`、复核单与配伍判定 `zfl31Review`、机台/染缸锁与交接记录 `zfl31Handoff`；旧排版台 `zfl31Pattern` 首次打开自动迁移。右上角可导出含三部分的 JSON。
