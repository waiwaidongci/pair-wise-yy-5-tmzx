# 手工织锦上机配伍台

直接打开 `index.html` 使用（无需构建，纯本地页面）。

在原排版台基础上扩为上机配伍台，解决两组色线来自不同染缸、换线出现色差的问题：

- **保存纹样即生成待复核用色清单**（复核单），按色位逐条登记染缸与批次。
- **同一染缸未晾干不能接下一份**：交接上机后染缸进入晾干倒计时（约 10 分钟），期间不可登记、不可开新批次。
- **批次色距未复测或与样卡不符即退回配色**：批次需复测出 ΔE，容差 ≤ 10，超标复核单退回并列出原因。
- **图案行列、色位、基础块一动，复核单立即失效**，页面提示重排，重新保存生成新版本。
- **画布数据、配伍判定、交接记录分别承载**：分别存于 localStorage 的
  `brocade.canvas.v1`、`brocade.compat.v1`、`brocade.handover.v1`，导出 JSON 亦按三段输出。
- 页面可见**机台占用**（占用中/空闲、上机时长、完工释放）、**待复核原因**（逐色位列出）与**历史版本**（可回排旧版纹样）。

## 文件

- `index.html` — 页面结构与样式
- `js/stores.js` — 三段数据存储（画布 / 配伍 / 交接）与种子数据
- `js/app.js` — 绘制、复核判定、染缸批次、机台交接、历史版本逻辑

## 基本流程

1. 绘制纹样 → 点「保存纹样·生成复核单」。
2. 在复核单中按色位选择染缸（晾干中的不可选）与批次；缺批次可在右侧开新批次并复测。
3. 点「复核判定」：有色距未复测或超差即退回配色，修好后再次判定。
4. 复核通过后选择空闲机台「交接上机」，染缸转入晾干，机台显示占用。
5. 机台完工后释放；历史版本面板可回排任一旧版纹样重新配伍。
